# Journal

A private record of one student's achievements and experiences, kept month by month so that nothing gets lost by the time university applications come around.

Entries cover things like competitions entered and results, leadership roles, projects, internships, volunteering, awards, and short reflections on what each experience taught him. Supporting files (certificates, logs, screenshots, drafts) sit alongside the entries for the month they belong to.

## How it's organised

Each month has its own folder, named with the year and month number first so the folders stay in date order on GitHub:

```
2026-10-October/
2026-11-November/
2026-12-December/
```

New folders get added as the months go on.
